## 第8章 魔兽‘迅猛龙’（上）

**概要**：地面震动的来源现身，希尔曼认出两层楼高、长二三十米的七级魔兽迅猛龙，立即与罗瑞、罗杰挡在孩子们前方。迅猛龙以红眸和锯齿般双排牙震住众人，背上的紫袍魔法师只确认这里是乌山镇，便驱使坐骑进镇。希尔曼尾随警戒，罗瑞、罗杰则告诉林雷：迅猛龙足以屠尽千人大队，而能将它收作仆从的紫袍人至少是七级、甚至八级魔法师。镇中央忽然传来怒吼，三名教官先后赶去，林雷也偷偷跟上。他拒绝返回，希尔曼只得把他留在身边保护；百米外，迅猛龙正与四男三女对峙。

**关键事件**：
1. 七级魔兽迅猛龙现身乌山镇，希尔曼三人挡在孩子前面
2. 迅猛龙背上的紫袍魔法师开口确认此处是乌山镇
3. 罗瑞、罗杰向林雷讲解迅猛龙的恐怖实力与紫袍魔法师更强的实力
4. 镇中央传来迅猛龙怒吼，林雷不顾劝阻跟随希尔曼留在身边

**逐章写法公式**：

- **情绪流向**：起：震动源现身造成集体惊呆 → 承：鳞甲、龙尾、牙齿持续放大恐惧 → 转：龙背主人出现，威胁层级再升一档 → 合：镇中怒吼引人追赶，四男三女进入对峙画面
- **节奏配比**：慢铺垫 20% / 快冲突 30% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：巨物现形兑现地动悬念 + 局部破坏细节建立七级威力 + 主仆关系抬高魔法师等级 + 怒吼与陌生青年把过境推向冲突
- **本章核心技巧**：采用两次“强者上方还有强者”的递进定级：先让普通战马在迅猛龙面前缩成婴儿，再让足以屠灭千人大队的迅猛龙成为紫袍人的坐骑，用空间位置和从属关系代替正面战斗完成实力排序。
- **卡点与伏笔**：结尾卡点：冲突阵列——迅猛龙前方出现四男三女，怒吼缘由与双方身份尚未揭开；埋设/回收伏笔：东方规律地动 → 回收为迅猛龙脚步，希尔曼尾随入镇 → 将训练场旁观者带到冲突现场，紫袍人确认“路没有走错” → 表明其来乌山镇有明确目的但尚未说明
