## 第1章 小镇早晨

**概要**：乌山镇的平民孩子照例由六级战士希尔曼带领晨练。希尔曼先展示伤痕、挥起三四百斤石锁并击碎青石，再讲解肉体与斗气的关系；第一次参训的六岁林雷在蕴气式和腰部悬空训练中都坚持到同龄人最后，引起三名教官注意。晨练后，希尔曼用四大终极战士和圣域强者毁山的传说激励孩子。林雷回到衰败的巴鲁克祖宅前，追问自己能否成为圣域战士，得到鼓励后主动要求加入九至十二岁的中央团队，希尔曼准许他次日越级训练。

**关键事件**：
1. 希尔曼向乌山镇平民孩子宣讲平民唯有靠锻炼身体出人头地，并组织蕴气式晨练。
2. 希尔曼脱衣展示伤痕、挥舞石锁、一拳砸碎青石，激起孩子们的崇拜。
3. 六岁的林雷·巴鲁克在腰部、蕴气式训练中坚持得超过十岁孩子，获希尔曼夸奖。
4. 希尔曼讲述四大终极战士与圣域强者的传说，并承认部分内容是为激励孩子而编。
5. 回家路上林雷追问能否成为圣域战士，希尔曼鼓励他，林雷主动要求加入中央团队。

**逐章写法公式**：

- **情绪流向**：起：小镇晨练的规律日常 → 承：六级战士示范带来的崇拜与热血 → 转：林雷两次坚持到同龄人最后并被单独关注 → 合：圣域传说点燃目标，越级训练形成下章期待
- **节奏配比**：慢铺垫 25% / 快冲突 20% / 爽点爆发 30% / 悬念留白 25%
- **本章结构公式**：集体晨练建立世界规则 + 强者示范树立实力标尺 + 同龄对比筛出主角 + 传说刺激转化为越级训练决定
- **本章核心技巧**：先用年龄分组和六级战士示范搭出清晰的实力刻度，再让六岁主角以两次“最后坚持者”越过刻度，最后把宏大传说收束成次日训练升级。
- **卡点与伏笔**：结尾卡点：行动升级——林雷获准进入九至十二岁团队，次日能否长期坚持越级训练待验；埋设/回收伏笔：四大终极战士传说 → 点燃林雷成为圣域战士的目标，巴鲁克五千年祖屋与经济衰败 → 将古老家族身份和现实困境并置，林雷超龄体能 → 支撑希尔曼批准越级训练
