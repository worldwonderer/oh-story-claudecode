## 第2章 龙血战士家族（上）

**概要**：半年后，希尔曼在深秋傍晚为一百二十六名即将参军的少年送行，既祝他们风光归乡，也暗自期盼十年后能有一半活着回来。霍格事先三次叮嘱林雷回家，希尔曼便把缺了一颗门牙的林雷带离空地。晚饭后，林雷陪两岁半的沃顿玩耍，希里随后传话将他叫进客厅。平日衣着简单的霍格换上华服，带林雷、沃顿与希里走入祭祖宗堂。密集灵位与烛火之下，霍格先说明家族已有五千年历史，再揭开四大终极战士对应四个古老家族，而巴鲁克家族正流有龙血战士血脉。

**关键事件**：
1. 希尔曼在东边空地为一百二十六名即将参军的少年送行并解散
2. 希尔曼应霍格之托带林雷回家，不让他与其他孩子玩
3. 林雷在府邸与弟弟沃顿嬉闹，沃顿讲述用麻布擦夜壶又擦碗
4. 林雷发现父亲霍格换上华贵衣服，被带往宗堂
5. 霍格在祖先灵位前揭示巴鲁克家族是蕴含龙血战士血脉的古老家族

**逐章写法公式**：

- **情绪流向**：起：参军送行的昂扬 → 承：教官预见伤亡的沉重与兄弟相处的轻松 → 转：华服、夜路、宗堂礼仪逐层收紧 → 合：家族血脉揭晓带来身份翻转
- **节奏配比**：慢铺垫 40% / 快冲突 10% / 爽点爆发 20% / 悬念留白 30%
- **本章结构公式**：集体送行展示尚武社会与军旅代价 + 家庭日常落出衰败生活 + 连续异常行动抬高家事规格 + 宗堂问答重释终极战士传说
- **本章核心技巧**：用“公开送行—家中嬉闹—夜入宗堂”三次场景降噪，把人物从三百人的空地逐步收拢到烛火前的父子对话，使血脉秘密获得与空间收束相匹配的分量。
- **卡点与伏笔**：结尾卡点：身份揭示——巴鲁克家族拥有龙血战士血脉，但血脉为何未使家族保持兴盛尚未说明；埋设/回收伏笔：霍格三次叮嘱与华服 → 为宗堂告密提高仪式等级，密集灵位与五千年传承 → 给龙血家族身份提供历史凭证，希尔曼讲过的四大终极战士 → 在父子问答中回收并转为林雷的家族秘密
