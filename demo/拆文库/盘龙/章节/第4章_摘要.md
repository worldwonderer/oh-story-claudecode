## 第4章 成长（上）

**概要**：血脉检测过去一年半，八岁的林雷已把静态张力练到十三四岁少年的水平。他不能修炼其他斗气密典，只能凭龙血血脉带来的体质优势苦练肉体，便以曾祖父达到七级为参照，立志冲击八级、九级，直到双臂剧痛、全身震颤才摔落休息。晨练后，林雷回府安抚来迎接的沃顿，洗净换衣接受霍格授课。他能复述大陆三大险地、东西势力与四大帝国，却记不清神圣同盟的公国数量，右手被荆条抽出血痕。霍格强调必须熟悉身处的同盟，随即翻开拳头厚的书，转讲石雕大师普鲁克斯。

**关键事件**：
1. 林雷在乌山镇东边空地做静态张力锻炼，回想父亲关于龙血战士血脉优劣的话，立志成为八级战士并坚持完成锻炼
2. 林雷回到府邸，沃顿迎接，林雷冲洗后准备上课
3. 霍格考查林雷复述玉兰大陆各国，林雷答不出神圣同盟公国数目，被荆条抽手留下血痕
4. 霍格转入艺术课，讲述石雕大师普鲁克斯

**逐章写法公式**：

- **情绪流向**：起：春日晨练中的拼劲 → 承：斗气绝路逼出更高肉体目标 → 转：回府答课失误、荆条落手 → 合：惩戒后继续学习，严格日常没有停顿
- **节奏配比**：慢铺垫 35% / 快冲突 15% / 爽点爆发 25% / 悬念留白 25%
- **本章结构公式**：极限训练呈现一年半成长 + 血脉限制解释刻苦根源 + 家庭短暂互动完成场景换气 + 地理考校与艺术课展示贵族培养
- **本章核心技巧**：把“成长”拆成身体和知识两场可失败的训练：前半让林雷主动撑到力竭，后半让他在父亲考校中因一个本地数字受罚，以不同代价显示成长不是概述而是重复执行的日常。
- **卡点与伏笔**：结尾卡点：课程切换——霍格由大陆格局转讲普鲁克斯石雕史，艺术教育将如何进入林雷的成长线尚未展开；埋设/回收伏笔：无法修炼普通斗气 → 固定林雷当前只能苦练肉体，曾祖父纯肉体七级 → 为八九级目标提供家族先例，普鲁克斯石雕课 → 将石雕知识首次纳入林雷的贵族教育
