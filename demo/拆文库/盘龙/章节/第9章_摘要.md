## 第9章 魔兽‘迅猛龙’（下）

**概要**：希尔曼看出紫袍魔法师与七人佣兵队争夺德佩洛影钻，自知六级实力无法插手，只带众人在远处旁观。影钻价值十万金币，紫袍人却只出七百并以性命威胁；红发队长拒绝交易，又试图抬出凯莱家族，对方直接命迅猛龙开战。烈焰先将石板路烧裂焦黑，四名战士撑起斗气护罩，劈塌石屋并把半米巨石接连踢向龙背，所有石块却被龙尾抽碎，周围石屋也随之倒塌。两名女魔法师完成咒语，为四名战士覆盖冰之守护战甲；红发队长取得双层防护后下令反攻，四人跃起十几米扑向迅猛龙。

**关键事件**：
1. 希尔曼判断魔法师与佣兵小队产生矛盾，决定旁观不插手
2. 林雷得知魔法师欲以七百金币强购价值十万金币的德佩洛影钻
3. 佣兵小队队长以凯莱家族背景施压，魔法师不予理会并下令开战
4. 迅猛龙喷火，四名战士用斗气护罩抵御并将石头当投石机踢向魔法师，被龙尾抽碎
5. 两名女魔法师施放冰之守护战甲，四名战士跃起朝迅猛龙激射进攻

**逐章写法公式**：

- **情绪流向**：起：远处观望中的力量评估 → 承：悬殊报价令谈判逐步冰冷 → 转：迅猛龙喷火，街道与石屋卷入战场 → 合：首轮投石被化解，双层防护推动佣兵队近身反攻
- **节奏配比**：慢铺垫 25% / 快冲突 35% / 爽点爆发 30% / 悬念留白 10%
- **本章结构公式**：影钻报价揭开争端本质 + 双方战力清单固定预期 + 火焰与投石完成首轮攻防 + 法师增益把战斗推入近身阶段
- **本章核心技巧**：把战斗拆成“环境取材—远程试探—防御验证—团队加持—近身突进”五个可见步骤，每一步都改变下一步选择，使迅猛龙抽碎巨石的结果成为佣兵队改用双层防护冲锋的直接原因。
- **卡点与伏笔**：结尾卡点：攻势悬停——四名战士已跃起十几米逼近迅猛龙，双层防护能否承受反击尚未揭晓；埋设/回收伏笔：德佩洛影钻价值十万金币 → 解释双方拒让但真正用途仍未知，女性魔法师从开战即吟唱 → 回收为四套冰之守护战甲，红发队长的凯莱家族身份 → 已被紫袍人无视，后续是否产生影响未明
