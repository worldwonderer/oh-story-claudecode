## 第7章 盘龙戒指（下）

**概要**：林雷离开古屋时踩到门槛边的硬物，原以为是碎木，反复踩压后发现一枚蒙尘黑戒。戒指似木似石，既无钻石也无魔法晶石，模糊纹路更像蚯蚓；林雷仍把唯一战利品命名为“盘龙戒指”。戒圈太大，他赶在傍晚训练前冲洗换装，从破麻布衣抽线将戒指穿成胸坠，塞进衣内后飞奔空地。迟到使他被希尔曼加罚一倍，少年们判断他将赶不上晚饭。林雷刚要归队，大地突然按固定节奏震动，仿佛庞然大物步步逼近；他辨出声音来自东方，希尔曼、罗瑞、罗杰也神色郑重地望去。

**关键事件**：
1. 林雷在门槛附近踩到硬物，抬脚发现并捡起一枚黑色戒指
2. 林雷判定戒指无钻石无魔法晶石一钱不值，仍将其命名为"盘龙戒指"
3. 林雷急忙洗浴换装，用麻布线将盘龙戒指穿成胸坠戴在胸前
4. 林雷迟到，希尔曼下令今日训练加罚一倍
5. 东方传来庞然大物迈步般的地面震动，众人望向东方

**逐章写法公式**：

- **情绪流向**：起：踩到硬物后的疑惑 → 承：捡戒、命名与制作胸坠的欣喜 → 转：赶训迟到并受双倍惩罚 → 合：规律震动逼近，轻松日常骤然悬停
- **节奏配比**：慢铺垫 35% / 快冲突 25% / 爽点爆发 10% / 悬念留白 30%
- **本章结构公式**：脚底异常促成拾戒 + 低价值判断反衬私人喜爱 + 赶训倒计时完成贴身携带 + 归队瞬间用地动切断日常
- **本章核心技巧**：先把标题物件写得像不值钱的儿童纪念品，让命名和佩戴完全出自主角喜爱；等戒指贴身后立刻把叙事切到全体都无法解释的地面震动，使私人小发现与外部大异常在同一时刻并存。
- **卡点与伏笔**：结尾卡点：未知逼近——东方传来庞然大物步行般的震动，所有教官与少年尚未看见来者；埋设/回收伏笔：门槛边黑戒 → 回收木架夹层掉落并由林雷拾得，似蚯蚓的扭曲雕纹 → 被林雷命名为盘龙但真实含义未明，胸前冰凉触感 → 确认戒指已长期贴身携带
