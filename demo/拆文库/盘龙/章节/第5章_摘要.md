## 第5章 成长（下）

**概要**：午间来客腓力打断授课，林雷从霍格强作笑容和“猛狮”石雕被抬出，意识到不向乌山镇征收重税的家族又在变卖旧物。腓力先以雕工不够顶尖压价五百金币，又把座钟报价抬到两千；霍格坚决不卖座钟，最终以六百金币卖掉猛狮。客人离开后，霍格望着六袋金币黯然，担心家产终会卖尽。林雷想到名家石雕价值上万乃至数十万金币，提出学艺替父亲解困，却被告知数百万人学雕、真正大师不足五人，多数工匠年薪仅几十金币。霍格命他午后清理宗堂，心中则想起自己苦学十年仍一钱不值。

**关键事件**：
1. 腓力到访巴鲁克府邸，霍格中止林雷的课程出门迎接
2. 腓力与霍格就石雕'猛狮'反复议价，腓力另出高价想买座钟被拒
3. 腓力以600金币买下石雕'猛狮'后离开
4. 林雷提出想学石雕改善家境，被霍格严厉否决并命去清洁宗堂
5. 霍格独自回忆自己学石雕十年却作品一钱不值

**逐章写法公式**：

- **情绪流向**：起：贵客到访的礼貌周旋 → 承：古物议价暴露家境窘迫 → 转：林雷提出靠石雕赚钱却遭严厉否决 → 合：父亲十年失败的隐情留下无声余味
- **节奏配比**：慢铺垫 25% / 快冲突 30% / 爽点爆发 10% / 悬念留白 35%
- **本章结构公式**：来客打断课程带出卖物目的 + 两轮报价划出家产底线 + 六袋金币短暂缓解困境 + 父子对石雕前景形成认知落差
- **本章核心技巧**：用同一门石雕连接“被卖的成品、孩子想象的高价名作、父亲十年无价值的作品”三种价格位置，使家境压力、林雷的天真方案和霍格的失败经验在一次交易后依次显形。
- **卡点与伏笔**：结尾卡点：认知反差——林雷刚想以石雕救家，霍格却以自身十年失败判定此路难通；埋设/回收伏笔：座钟两千金币仍不卖 → 标记家中尚有不可轻易割舍的旧物，午后清洁宗堂 → 把林雷下一步行动引向祖宅后院，霍格学雕十年无成 → 为他熟悉石雕门槛与严厉否决提供事实根源
