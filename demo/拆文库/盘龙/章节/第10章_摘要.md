## 第10章 火蛇之舞（上）

**概要**：迅猛龙喷火覆盖数十米，四名战士凭冰甲与斗气护罩硬抗，女弓手则骑狮鹫射出三连矢。龙尾快过箭矢，击碎三箭后反扫战士；路加的双层防护瞬间破裂，人被卷入龙口咬死。希尔曼遮挡已晚，八岁的林雷目睹惨状后一度呼吸困难、头脑眩晕，却反复劝自己挺过恐惧，随后血液沸腾并继续观战。剩余三名战士悲愤突进时，紫袍人完成暗中吟唱，释放八级魔法“火蛇之舞”，七条数十米火蛇飞向四方。佣兵队终于确认对方是八级魔法师，红发队长急喊逃跑，紫袍人却宣告已经来不及。

**关键事件**：
1. 女弓箭手骑狮鹫射出三连矢攻击迅猛龙背上的神秘魔法师，被龙尾砸碎
2. 战士路加被龙尾卷入迅猛龙口中咬碎，半截大腿跌落
3. 林雷目睹血腥场景后由呼吸困难转为血液沸腾、产生杀戮渴望
4. 神秘魔法师释放八级魔法火蛇之舞，七条火蛇飞出
5. 佣兵小队得知对方是八级魔法师，红发壮汉喊逃

**逐章写法公式**：

- **情绪流向**：起：火海中双层防护带来短暂稳定 → 承：龙尾破箭并杀死路加，恐惧落到具体伤亡 → 转：林雷压住生理不适后主动继续看 → 合：七条火蛇显明八级身份，佣兵由反攻转为绝望逃亡
- **节奏配比**：慢铺垫 15% / 快冲突 40% / 爽点爆发 25% / 悬念留白 20%
- **本章结构公式**：远程箭击验证龙尾速度 + 首名队员死亡打破防御预期 + 旁观少年完成恐惧转化 + 隐蔽吟唱兑现八级范围魔法
- **本章核心技巧**：用两次防线崩塌抬升危险：路加的冰甲与斗气先被龙尾瞬破，佣兵队“还能与七级拼一会儿”的整体判断再被八级火蛇推翻，让个体死亡和团队溃败共享同一升级逻辑。
- **卡点与伏笔**：结尾卡点：范围魔法待落——七条火蛇已飞向四面八方，六名佣兵刚转身求生，能否逃出覆盖尚未呈现；埋设/回收伏笔：紫袍人持续微动嘴唇 → 回收为八级咒语吟唱，罗杰曾推测可能是八级魔法师 → 由火蛇之舞证实，林雷瞳孔激动红光与杀戮渴望 → 血脉是否影响战斗反应仍无定论
