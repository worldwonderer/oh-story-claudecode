## 第16章 灾难（上）

**概要**：黑龙喷出的黑焰被蒂隆以碧绿斗气挡住，他随即挥出数十米剑芒；鲁迪一边念咒，一边任剑芒劈碎灰袍，靠钻石般的护体战甲毫发无伤。随后，密集的十万斤巨石围攻蒂隆，却被其斗气全部震裂。碎石从数百米高空向四周迸射，约五分之一落入乌山镇，砸穿屋顶、石板与人体。林雷奔向库房时屡次险被击中，发现一块近两米巨石将砸向门口的沃顿，便放弃闪避扑住弟弟。巨石击塌库房，希里爆发斗气赶来保护，三人一同被墙壁掩埋；霍格目睹全过程，却无法判断希里和碎石谁先压到林雷。

**关键事件**：
1. 蒂隆以碧绿色斗气护体并挥出巨型剑芒，鲁迪靠护体战甲免伤
2. 鲁迪召出密密麻麻巨石砸向蒂隆，蒂隆斗气爆发将巨石震裂
3. 碎石从高空朝乌山镇四散迸射，灾难降临
4. 林雷飞扑压住库房门口的沃顿
5. 库房被砸塌，林雷、沃顿、希里三人被墙壁掩埋

**逐章写法公式**：

- **情绪流向**：起：黑焰、剑芒与护甲连续互验，战斗仍属观赏震撼 → 承：房屋巨石被斗气震碎，危险突然外溢 → 转：落石砸镇，林雷从逃生转为救弟 → 合：兄长与管家接力保护，三人被埋、生死状态难辨
- **节奏配比**：圣域攻防 30% / 余波成灾 25% / 林雷避险与判断 20% / 扑救崩塌 25%
- **本章结构公式**：顶级攻防展示 + 防守破招制造二次抛射物 + 远景灾害落到镇中声音与伤亡 + 主角发现亲人处于撞击路径 + 两次飞扑保护后以掩埋截断
- **本章核心技巧**：把高空战斗的宏观奇观沿“十万斤巨石—碎成数十上百块—五分之一落镇—数百斤擦身—两米巨石砸库房”逐级缩小，最终落到林雷扑住四岁弟弟这一具体选择，使灾难尺度与人物情感在同一条因果链上收紧。
- **卡点与伏笔**：章尾生死卡点：沃顿、林雷、希里已被倒塌墙体完全掩埋，霍格无法判断是希里的护体气罩先覆盖林雷，还是碎石先击中他；战局伏笔：鲁迪的土系巨石魔法与蒂隆的碧绿斗气仍在高空交锋，镇区还处于持续落石之下，灾难尚未停止
