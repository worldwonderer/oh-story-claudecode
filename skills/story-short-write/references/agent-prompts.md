# 短篇写作 Agent 增强提示词

完整版 Agent 调用 prompt 模板。SKILL.md 中保留调用签名（一句话摘要），此处为详细版本。

---

## Phase 1：story-architect — 情绪目标审查

```
你是故事架构师。审查以下情绪目标选择是否合理，建议最适合的题材方向和核心梗。
情绪目标：{用户选择的情绪}。题材方向：{用户的想法或'未定'}。
以最严苛标准审视，指出潜在风险并给出更优方向。
```

触发时机：用户选定情绪目标后、进入 Phase 2 前，可选调用（串行）。

---

## Phase 2：story-architect — 核心框架审查

```
你是故事架构师。审查并优化以下核心框架 — 反转设计质量、钩子强度、情绪弧线合理性。
文件路径：{设定.md}。
上下文：{核心框架摘要 + 小节大纲}。
以最严苛标准审视，找出所有可改进处。
```

触发时机：核心框架确定后调用（串行），可与 character-designer 并行。

---

## Phase 2：character-designer — 人设速写审查

```
你是角色设计师。审查以下人设速写 — 语言风格档案差异化、动机链完整性、关系合理性。
文件路径：{设定.md}。
上下文：{人设速写全文}。
以最严苛标准审视，确保每个角色有独立的声音和动机。
```

触发时机：核心框架确定后，与 story-architect 可并行。

---

## Phase 3：narrative-writer — AI味和节长检查

```
你是叙事写手。检查以下已写段落的 AI 味和节长达标情况。
文件路径：{正文.md}。已写节号：{X}-{Y}。
参考：anti-ai-writing.md 禁用词黑名单。
逐节检查：(1) AI 腔词句 (2) 节长是否 ≥800 字 (3) 三层展开是否完整。
输出具体修改建议。
```

触发时机：每写完 2-3 节后调用（串行），可选。

---

## Phase 4：consistency-checker — 全文一致性扫描

```
你是一致性检查员。对以下作品执行全文一致性扫描 — 角色属性矛盾、伏笔断线、时间线冲突。
文件路径：{正文.md}、{设定.md}。
输出 S1-S4 分级冲突报告，包含具体节号和原文引用。
```

触发时机：精修完成后调用（串行）。
