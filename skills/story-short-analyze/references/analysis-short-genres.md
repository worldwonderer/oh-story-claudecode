# 短篇源文题材识别标尺

> 只用于识别和比较已经存在的短篇源文。它描述可观察的读者承诺、冲突载体与常见失效方式，不提供写作步骤，不拿长线开篇或卷级模型衡量短篇。

## 使用方式

先根据全文证据给出一个主类型，必要时再给一个副类型。题材名称不能只由标签、背景或单个桥段决定。

每个题材判断都要回答：

1. 源文持续交付的核心情绪是什么？
2. 哪些可定位情节承担了这个承诺？
3. 结尾实际结算了什么？
4. 若存在混合题材，哪个负责主线，哪个只提供手段或氛围？

## 题材路由

| 类型 | 可观察识别锚点 | 核心读者承诺 | 容易混淆 |
|---|---|---|---|
| 追妻/追夫火葬场 | 伤害、离开、追悔、拒绝或有代价的和解构成因果链 | 迟来的认知与关系权力反转 | 普通虐恋只有痛苦，没有追悔后的主动权变化 |
| 重生复仇 | 前世信息改变今生选择，旧因果被重新结算 | 信息差带来的纠错、报应或遗憾弥补 | 只有重生设定但关键选择未改变，不构成机制 |
| 婚恋/家庭世情 | 日常利益、亲缘伦理、财产或照护责任推动冲突 | 熟人关系中的不公被看见并结算 | 悬疑可作取证手段，不一定是主类型 |
| 虐渣/公开审判 | 主角掌握并选择释放证据，反派承受可见后果 | 压抑后的公开反击与责任归位 | 天降报应会削弱主角代理权 |
| 悬疑/推理 | 证据解释不断变化，真相改变行动或责任判断 | 公平的信息控制与认知修正 | 只有神秘氛围、没有可复核证据链，不足以定为悬疑 |
| 细节线索复仇 | 物件、记录、时间或措辞异常逐步组成责任链 | 小异常扩成可证明的真相 | 线索若只负责气氛，不改变判断，就不是结构支点 |
| 死人文学/灵魂视角 | 死亡或缺席改变信息分配，生者在来不及中重新理解关系 | 亏欠、追悔与不可逆损失 | 死者视角只是旁白形式时，不一定是主类型 |
| 甜宠/关系喜剧 | 关系推进、反差或共同困境持续带来正向回报 | 安全感、亲密感与轻冲突兑现 | 不应强行用反转或复仇标尺判定密度 |
| 民俗/规则怪谈 | 明示或暗示的规则约束选择，违规产生可追溯后果 | 规则验证、求生判断与未知压力 | 规则随时改写会破坏公平性 |
| 都市系统/脑洞 | 单一异常机制改变现实问题的解法，规则、限制和代价可追踪 | 看新机制如何被使用、误用或放弃 | 不因出现系统就套长线升级或地图扩张结构 |
| 仙侠/玄幻短篇 | 少量超凡规则服务一个完整矛盾与情感结算 | 陌生规则中的选择、代价或身份反转 | 世界观层级多不等于结构完整 |
| 历史/架空短篇 | 历史情境或认知差直接改变一次关键选择 | 已知节点被重新解释或改写 | 盘点知识若不进入人物因果，只是背景信息 |
| 娱乐圈/职场 | 专业能力、组织权力和公众评价参与冲突结算 | 能力被验证、权力被反制或身份被重估 | 反应链过多但主线无变化时只是围观噪音 |
| 同人 | 已知世界或角色关系被一个新变量改写 | 熟悉感与偏差带来的再解释 | 只有名称借用、没有原关系功能，不足以定为同人结构 |

## 混合题材判定

用下面的证据优先级区分主次：

| 优先级 | 问题 |
|---|---|
| 主线所有权 | 删除该类型后，核心目标与因果链是否仍成立？ |
| 高潮所有权 | 最终不可逆选择在结算哪一种冲突？ |
| 情绪所有权 | 读者最后得到的是爽、痛、甜、恐惧、释然还是认知震荡？ |
| 手段与目的 | 悬疑、系统、重生等是故事要结算的对象，还是帮助另一条主线推进的工具？ |

若两种类型都能删而不影响主线，题材证据不足；报告为“通用短篇 + 元素标签”，不要强行归类。

## 报告格式

```markdown
主类型：{类型}
副类型：{可选}
定位证据：{节次/原句/情节点}
主线所有权：{哪类冲突拥有高潮与结算}
符合常见模式：{观察到的功能，不写合格/不合格}
偏离或改造：{源文如何改变常见模式}
不确定项：{证据不足/待复核}
```

## 失效检查

- 不把推荐比例、固定节数或某种平台模板当成题材成立条件。
- 不因出现“系统、修仙、历史”等标签就调用长篇升级与卷级标尺。
- 不用“必须有某场景”替代源文证据；缺少常见场景只说明偏离，不自动说明失败。
- 不把作者意图写成事实；只报告文本持续交付了什么。
