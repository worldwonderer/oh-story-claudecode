# 多对标六维拆书召回

跨书召回只复用六维拆书产物，不建立额外公共目录，也不把副对标原文送入写作上下文。

- **主对标**：提供 `全局分析/爆款机制.md`、`全局分析/六维拆书.md`、`全局分析/证据与边界.md`、`structure_blocks.csv`、五列 `chapter_index.csv` 和定点原文。
- **副对标**：只提供三个全局文件；不读取其结构块、索引或原文。
- **当前作品**：对标发现必须排除当前作品及其 `拆文库/` 目录，不得把自己当作外部对标。

## 1. 召回输入

按当前任务整理：题材、读者需求、目标情绪、关系动作、剧情功能、节奏位置、适用阶段和需要规避的风险。主对标由 `设定/题材定位.md` 的登记决定；副对标最多选择 2 本，且必须与至少一个输入维度直接相关。

## 2. 主对标通道

1. 读取 `全局分析/爆款机制.md`，选 1–3 个与任务直接相关的机制。
2. 读取 `全局分析/六维拆书.md` 的人物关系、双时间线与三维节奏章节，确定关系动作、披露顺序和峰谷位置。
3. 用 `全局分析/证据与边界.md` 排除低置信结论、反例和不可迁移项。
4. 从 `structure_blocks.csv` 选择 1 个候选块，再用五列 `chapter_index.csv` 把块内章号映射到 `source_locator`。
5. 仅在需要文风或事实核证时读取命中的 1–2 章主对标原文。索引标题不能代替原文事实。

缺少上述当前契约产物时 fail-fast，返回 `missing_primary_contract: true` 和明确 `repair_action`；不得以历史逐章摘要、旧拆文报告或索引标题补造内容。

## 3. 副对标通道

每本副对标只读三个全局文件，提取一个补充机制，并记录：来源书、机制 ID、读者效果、成立条件、可替换项、证据等级与误用风险。最多保留 2 个补充机制；没有直接命中就不补。

副对标只用于比较机制边界：不读取副书原文，不提炼副书文风，不把多本书拼成固定模板。

## 4. 优先级与预算

| 阶段 | 主对标机制 | 副对标机制 | 主对标原文 |
|---|---:|---:|---:|
| 设定 | 1–3 | 0–2 | 0 |
| 卷纲 | 1–3 | 0–2 | 0–1 章 |
| 细纲批 | 1 | 0–1 | 1–2 章 |
| 正文单章 | 1 | 0–1 | 1 章，最多 2 章 |

自定义 `设定/文风.md` 含实质内容时始终是最高风格优先级。全局机制与节奏可以约束结构，但不能覆盖作者文风、已确认细纲或项目事实。
