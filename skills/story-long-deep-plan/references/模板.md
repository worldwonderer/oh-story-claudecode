# 长篇深层规划模板

按需使用这些模板。除非用户要求完整项目设定集，否则保持输出精炼。

---

## 主题问题

```markdown
# 主题问题

- 核心问题：
- 为什么这个问题适合长篇：
- 读者表层情绪：
- 深层情绪：
- 不能写成的口号：
- 必须落地的剧情选择：
- 本问题在终局的回答：
```

---

## 思想谱系

```markdown
# 思想谱系

## 思想位置：{名称}

- 代表人物：
- 核心信念：
- 形成原因：
- 它保护了什么：
- 它伤害了谁：
- 自我辩护：
- 与男主的关系：吸引 / 诱惑 / 压迫 / 镜像 / 反驳
- 适合碰撞的场景：金钱 / 亲情 / 权力 / 生死 / 梦想 / 背叛 / 名额 / 体面
- 最终会被证明的部分：
- 最终会破产的部分：
```

## 象征系统

```markdown
# 象征系统

## 象征物：{名称}

- 表层物件 / 动作 / 场所：
- 关联主题：梦想 / 阶层 / 自由 / 体面 / 亲情 / 失败 / 逃离
- 第一次出现：章节 | 场景 | 初始意义
- 第二次出现：章节 | 场景 | 意义污染或反转
- 第三次出现：章节 | 场景 | 情感结算
- 上层人物如何理解：
- 中层人物如何理解：
- 下层人物如何理解：
- 男主的理解如何变化：
- 禁止解释方式：
```

## 深层卷纲

```markdown
- 象征物出现与意义变化：

- 下层视角：

```
