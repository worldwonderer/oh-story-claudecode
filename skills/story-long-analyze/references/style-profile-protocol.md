# 文风画像协议

> **何时加载**：story-long-analyze Stage 6 执行前。下游写作 skill 直接读 `文风画像.md`，不加载本协议。

## 产物定义

`拆文库/{书名}/文风画像.md` 是整书级写作技法视图，聚合：

- 句长 / 标点 / 段落节奏（从原文采样统计）
- 对话潜台词模式 + 角色语气区分
- 章内 + 跨章情绪交替周期（从 tone 序列推断）
- `拆文报告.md` 已有的「写法技巧」「可借鉴套路」
- 4-6 段 300-500 字原文锚点片段（few-shot 用）

## 文件路径

- **写**：`拆文库/{书名}/文风画像.md`（analyze 独占）
- **读**：story-import 同步到 `{项目}/对标/{书名}/文风画像.md`；story-long-write 读项目对标视图（回退拆文库）

## 字数预算

- **硬上限 ~4000 字**
- 描述部分（整体语感 + 对话技法 + 情绪交替模式 + 可借鉴技巧）≤ 1500 字
- 原文锚点片段 4-6 段 × 300-500 字 ≈ 1600-2400 字
- 不可模仿 + 生成元信息 ≤ 100 字

## confidence 字段语义

| 值 | 触发条件 | 下游处理 |
|---|---|---|
| `high` | 数据直接可读（如 tone 序列从摘要 grep 得出） | narrative-writer 优先采纳，覆盖默认 Gate |
| `med` | 派生但样本充足（如 3 章原文抽样统计） | narrative-writer 参考，与默认 Gate 协商 |
| `low` | 派生且样本不足/原文缺失 | narrative-writer 让位回默认 Gate（不强制采纳） |

## degenerate 字段语义

- `degenerate: false`（默认）→ 画像可用，narrative-writer 按 confidence 分级使用
- `degenerate: true` → 整书画像质量太差（原文缺失 + 全段 low confidence + 锚点片段全是占位符）。story-explorer 读取时返回 `gaps.profile_degenerate: true`，narrative-writer 跳过画像，按默认 Gates 写作（避免被误导）

## 覆盖与不可模仿原则

- **覆盖**：画像优先级排在 Gate D（句长拆短）、Gate B（句式去套路）、标点默认习惯之上——这些 Gate 是去 AI 味的**默认值**，画像有更具体的指令时画像赢。
- **不可覆盖（硬约束）**：banned-words / Gate F 章末禁升华 / 禁止万能比喻 / 禁止章末预告 / 字数下限——这些硬约束永远赢，即使画像示范了相反的用法。

精确决议表见 `.claude/agents/narrative-writer.md` 的"被调用协议"段。
