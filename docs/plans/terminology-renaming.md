# 术语重命名计划 v2

## 目标
将 reference 文件中的晦涩自造术语改为 AI agent 一眼能理解的名称。
核心标准：**名称本身传达"这是什么"和"什么场景下用"**。

## 命名原则

1. **去隐喻**：不用比喻（手弩/竹子/狗哨/悬崖挂壁），用直白操作描述
2. **场景嵌入名称**：名称暗示使用场景（如"章末断章留悬念"比"悬崖挂壁"清晰）
3. **保留行话**：网文圈通用术语不改（金手指、装逼打脸、断章、倒计时、系统流）
4. **保留已清晰术语**：已被广泛理解或有价值视觉隐喻的名称不改（情绪折线、Hook上瘾模型）
5. **不动单字后缀**：法则/模型/理论等后缀若非隐喻则不改——改了不增加理解，反而增加同步成本
